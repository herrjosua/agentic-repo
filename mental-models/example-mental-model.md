## Overview
Covers how new admins conceptualize "setting up a workspace" before they've
used Fernway, versus how the system actually models the task.

## Model
Admins think of setup as one task with optional extras ("connect stuff if I
want to"). The system actually models it as a required linear sequence where
several "extras" (like calendar connection) gate later functionality. This
mismatch is the root cause behind the step-3 confusion seen across research.
