# agentic-repo

Agentic UX research and design-tokens repo.

- `research/` — raw notes, synthesized findings, and the index
- `design-tokens/` — canonical DTCG tokens synced from Figma, plus an agent-readable Markdown layer
- `docs/` — schema and workflow documentation

See `AGENTS.md` for the schema and conventions any agent working in this repo should follow.
