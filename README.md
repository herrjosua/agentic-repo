# agentic-repo

A git-tracked research memory + design-ops mirror for the Compass AI program: UX research findings
an agent can be pinged about months later, and a Markdown view of the Figma design system so an
agent doesn't need Figma access to reference it.

- **For agents:** see `AGENTS.md` (Claude Code reads `CLAUDE.md`, which imports it).
- **For humans:** start at `research/_index.md` for a scan of everything researched so far, or
  `design-tokens/design.md` for the current token/component reference.
- **Project background & build plan:** `docs/`

> This repository's content (research sessions, findings, design tokens) is **entirely fictional
> sample data** for a hypothetical healthcare organization ("Meridian Health Network") and its
> "Compass AI" modernization program. No real patients, staff, or PHI are represented.
